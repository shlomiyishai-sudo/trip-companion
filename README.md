# Trip Companion · הטיולים שלנו

אפליקציה אישית לתכנון וליווי טיולים, של שלומי ואדווה. הטיול הראשון: בודפשט, 8–12 בנובמבר 2026.

**כתובת:** https://shlomiyishai-sudo.github.io/trip-companion/

## איך זה בנוי
- `data/budapest.js`: כל נתוני הטיול (מקומות, שכבות, תוכנית יומית, הזמנות, טיפים). לטיול הבא יוצרים קובץ חדש באותו מבנה.
- `app.js`: האפליקציה (מפת גוגל, מסלולים, מזג אוויר, כפתורים מהירים).
- `config.js`: מפתח גוגל מפס, נעול לכתובת האתר בלבד.
- אין במאגר מידע רגיש. מספרי הזמנה ודרכונים יישמרו באזור פרטי נפרד.
